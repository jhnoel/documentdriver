# Rubric: au-ow-chevrons (not yet automated)

Judge the PowerPoint render of slide 1 (LibreOffice if PowerPoint is not
available, noting it). Score each item pass/fail; the task passes the
rubric when all items pass.

1. Five chevron (arrow-like) shapes form one left-to-right row below the
   existing diagram, reading Event, Trigger, Rule, Action, Result.
2. Each label is fully visible inside its chevron (no clipping or
   overflow) and legible against the fill.
3. The chevrons point to the right and nest or touch consistently, so the
   row reads as one process.
4. The row does not overlap the existing diagram or run off the slide.
5. Nothing else on the slide looks different from the input render.
