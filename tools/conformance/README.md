# tools/conformance

`vsdx-schema-check.py` is the opt-in MS-VSDX schema check, run as `make vsdx-schema-check` (with `INPUT=`, `OUTPUT=`, `ARGS` or `VSDX_SCHEMA_CHECK_ARGS`, or directly with `uv run --script tools/conformance/vsdx-schema-check.py --input in.vsdx --output out.vsdx`): it loads the XSD from the gitignored schema cache (`$VSDX_SCHEMA`, default the main checkout's `corpus/vsdx-schema`, filled by `make vsdx-schema`, pinned by sha256 and never committed) with `xmlschema.XMLSchema11`, rewrites a 2012/main instance's namespace to 2011/1/core in memory, validates every Visio part of the given inputs and outputs, and fails only on error kinds (reason, element path with indexes removed) an output has that its input did not, listing the input's own errors as known — V1's page, for example, reports exactly three known kinds (`xml:space` not allowed on PageContents, an assertion on Section, character data in Text) and passes as an input, while an output with a `<Bogus/>` child in a Shape fails naming it — and without a valid cache it skips with exit 0 and one line (`no schema cache: run make vsdx-schema`); it is never part of `make check` or `make ci`.
