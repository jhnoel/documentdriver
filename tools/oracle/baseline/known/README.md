# Known differences from docxdriver 0.5.2

Intended differences the comparators accept, one file per case family so
the agents porting each family list theirs without editing the same
file. tools/oracle is owned by P4d: other agents send their entries to it.
Anything unlisted still fails.

| File | Family | Format |
| --- | --- | --- |
| `read.tsv` | read, find and the HTML projection (`oracle compare`) | set, file, case, reason; evidence in `../README.md` |
| `write-paraid.tsv` | generated by `oracle write gen` (P4a): repaired paraIds | plan id, mode, field, reason |
| `write-engine.tsv` | engine-level differences (P4a, P4c) | plan id, mode, field, reason |
| `write-oracle-bugs.tsv` | docxdriver bugs found while recording, with evidence (W1-W9) | plan id, mode, field, reason |
| `write-ops.tsv` | per-operation differences, filled by the P5 waves | plan id, mode, field, reason |
| `write-plan.tsv` | invalid-plan parity: the negative, rule and schema kinds of all 42 operations (P4 close-out); generated from a compare run and reviewed, each a path or code the contract fixes | plan id, mode, field, reason |

`oracle write compare` reads every `write-*.tsv`. A plan id ending in `*`
matches a prefix; mode is `track`, `direct` or `*`; field is `outcome`,
`code`, `path`, `proj:<name>`, `integrity`, `dropped`, `part:<part>` or
`*`, and a field ending in `*` matches a prefix (`proj:*`). A case
counts as intended only when entries account for every field that
differs.
